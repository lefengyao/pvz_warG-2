## 验证中处理的问题

1. **缺失插件的旧配置**：基线扫描发现 `godot_daedalus` 不在项目中；Godot 将其禁用，本次去除失效配置。
2. **移动音频总线后的配置**：使用正确的 `audio/buses/default_bus_layout` 显式指定新位置，确认 `music`、`sfx` 两个总线存在。
3. **项目外存档中的旧引用**：旧 `user://audio_settings.tres` 未存储脚本 UID，而是记录旧路径。Settings 在 UI 加载之前先备份，再通过临时文件更新脚本路径，保留音量。备份为原存档旁的 `audio_settings.tres.before_layout_migration.bak`。
4. **原选卡逻辑的临时实例未释放**：用于读取植物配置的临时实例未进入场景树且未释放；未选中的卡片实例也没有父节点。已在读取后释放临时植物，退出选卡时释放未转入战斗 UI 的卡片。取消重选、全选和部分选择均已覆盖。
5. **测试退出时的音频清理**：测试结束前停止播放器并等待音频线程释放，避免将仍在播放的音频误报为测试退出泄漏；正常游戏音频逻辑不变。
